# MyCrew Desktop — 用户指南

## 概述

MyCrew 是一个本地运行的 AI 多 Agent 协作桌面应用。通过 MCP（Model Context Protocol）连接外部工具（Unity、Blender、ComfyUI 等），结合多家 LLM API，实现自动化工作流编排。

## 首次使用

### 1. 配置 LLM

打开应用 → 侧边栏点击「设置」→ 选择「LLM」Tab：

1. 点击「+ 新建」添加 LLM 提供商
2. 填写名称、类型（OpenAI / Claude / Qwen / Deepseek 等）
3. 填写 API Key 和 Base URL
4. 添加该提供商下的模型（如 gpt-4o、claude-sonnet-4-20250514 等）
5. 在「默认 LLM」区域选择立项默认和 Agent 默认模型

### 2. 配置 MCP 服务器

设置页 →「MCP」Tab：

1. 点击「+ 新建」添加 MCP 服务器
2. 选择协议类型（stdio / HTTP）
3. stdio 模式：填写启动命令和参数
4. HTTP 模式：填写服务器 URL
5. 可选：配置环境变量、超时时间、自动启动

### 3. 配置权限

设置页 →「权限」Tab：

控制 Agent 的操作权限：
- **文件读取**：允许 Agent 读取本地文件
- **文件写入**：允许 Agent 写入/创建文件
- **命令执行**：允许 Agent 执行系统命令
- **网络访问**：允许 Agent 发起网络请求
- **MCP 调用**：允许 Agent 调用 MCP 工具

## 创建项目

### 对话式立项

1. 主页点击「新建项目 +」
2. 在对话框中用自然语言描述你的项目想法
3. AI 会将想法拆解为多个可执行任务
4. 右侧面板显示任务蓝图，可编辑：
   - 任务标题和详情
   - 负责的 Agent
   - 前置依赖关系
5. 确认后生成项目卡片

### 项目卡片操作

每张项目卡片支持：
- **开始**：启动工作流执行
- **继续**：恢复暂停的工作流
- **迭代**：基于已完成项目创建新迭代
- **路径**：设置项目工作目录
- **复制**：复制项目配置
- **删除**：删除项目

## 任务执行

### 任务页

点击项目卡片进入任务页，查看：
- **DAG 蓝图**：任务依赖关系的有向无环图
- **任务节点**：每个节点显示状态（待执行/执行中/已完成/失败）
- **IO 查看器**：查看任务的输入输出数据
- **Agent 对话**：查看 Agent 执行过程中的对话记录

### 任务状态

| 状态 | 说明 |
|------|------|
| pending | 等待前置任务完成 |
| running | Agent 正在执行 |
| completed | 执行成功 |
| failed | 执行失败 |
| paused | 用户暂停 |

### 人工介入

当 Agent 需要人工确认时，任务会暂停并弹出交互请求。用户可以：
- 批准操作继续执行
- 拒绝并提供修改意见
- 手动编辑任务参数后重试

## 团队管理

### Agent

团队页 →「Agents」Tab：
- 查看所有已创建的 Agent
- 编辑 Agent 的角色、目标、背景故事
- 配置 Agent 可用的 Tool 和 MCP 服务器
- 启用/禁用 Agent

### Crew

团队页 →「Crews」Tab：
- 创建 Agent 协作组
- 选择执行模式：顺序（Sequential）或层级（Hierarchical）
- 配置 Crew 成员

### Tool

团队页 →「Tools」Tab：
- 查看内置工具和自定义工具
- 自定义工具放置在 `src/tools/` 目录
- 支持 BaseTool 和 Decorator 两种编写方式

## MCP 连接监控

主页底部状态栏实时显示：
- **MPC连接**：各 MCP 服务器连接状态（绿点=已连接，红点=断开）
- **Tokens**：各 LLM 的 token 使用量百分比

## 主题切换

侧边栏底部的主题切换按钮支持三种模式循环：
- ☀️ 浅色模式
- 🌙 深色模式
- 💻 跟随系统

## 故障排查

### MCP 连接失败
1. 确认 MCP 服务器进程已启动
2. 检查设置页中的命令/URL 配置是否正确
3. 点击主页底部「连接」按钮手动重连
4. 点击「刷新」按钮刷新连接状态

### LLM 调用失败
1. 检查 API Key 是否正确
2. 确认 Base URL 可访问
3. 检查网络连接
4. 查看日志面板获取详细错误信息

### 任务执行卡住
1. 检查 Agent 对话记录是否有交互请求等待响应
2. 尝试暂停后重新开始
3. 检查相关 MCP 服务器连接状态
